# EvidencePDF - 法律/财务 PDF 证据提取 MVP

一个可本地运行、可解释的企业文档证据提取工具。批量上传 PDF，输入目标字段（例如“研发投入, R&D expenditure”），系统按页检索、提取数值候选、导出证据页，并生成 Excel、Word 和 ZIP 结果包。

> MVP 定位：优先解决“可搜索文本型 PDF”的证据定位与归档。扫描件 OCR、复杂跨页表格和大模型语义检索列入后续版本。

## 功能

- 批量上传企业财报或法律/合规 PDF
- 用户只输入一个指标；内置词典自动扩展中英文及其他常见语言近义词
- 企业名称、报告年份、语种和文件类型优先从 PDF 正文识别，不依赖随机文件名
- 页级关键词评分，展示命中词、证据片段和数值候选
- 可设置每份文件最多保留的证据页及最低匹配分
- 按规范导出单页证据 PDF：`序号_企业名称_语种_年份_原文件类型_p页码.pdf`
- 生成 Excel 结果表与 Word 证据清单，单独保留原文币种与金额单位
- 一键下载包含证据 PDF、Excel、Word 和清单文件的 ZIP
- 默认只在内存和临时目录处理文件，不上传第三方服务

## 快速开始

要求 Python 3.9+。

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开终端显示的本地地址（通常是 `http://localhost:8501`）。

如果不熟悉命令行，Mac 用户可以直接双击项目中的 `启动工具.command`。第一次运行会自动创建环境并安装组件。详细步骤见 `小白使用说明.md`。

## 使用方法

1. 上传一个或多个文本型 PDF。
2. 输入一个目标指标，如 `研发投入`；系统会自动使用内置多语言近义词。
3. 可选填写默认企业名称、年份和文件类型；系统也会尝试从文件名识别。
4. 点击“开始提取”。
5. 核对候选结果，下载 ZIP、Excel 或 Word。

建议源文件名包含企业名和年份，例如 `华星科技_2024_年度报告.pdf`。程序不会把候选数值当作经人工确认的最终事实；正式法律或财务工作中应回看导出的证据页。

## 技术设计

- **界面：** Streamlit，开发成本低，适合本地演示。
- **PDF：** `pypdf` 解析文本和复制原始证据页，避免重排造成证据失真。
- **检索：** 先使用精确指标，再按内置多语言近义词回退；命中结果可追溯。
- **数值候选：** 要求“指标/金额语义 + 数值 + 单位上下文”共同成立，排除章节编号、专利数、人数和比例等非金额数字。
- **元数据：** 企业名称与报告年份从正文标题/页眉识别；文件名只作为来源记录。
- **导出：** `openpyxl` 生成可筛选 Excel，`python-docx` 生成 Word 清单。

核心流程：`上传 -> 逐页解析 -> 字段匹配/评分 -> 证据候选 -> 原页复制 -> 表格与结果包导出`。

## 已知限制

- 扫描版 PDF 若无文本层会被标记为“可能需要 OCR”，当前不自动识别图片文字。
- 数值候选基于邻近文本模式，不理解复杂表头、单位继承或跨页表格。
- PDF 加密、损坏或字体编码异常时，文本提取效果取决于源文件。
- 文件名元数据识别是启发式的，导出前应在页面中检查。

3. 增加本地向量检索或可选 LLM 复核，并保留引用链。
